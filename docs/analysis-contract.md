# 分析资料与解释边界

## 抽样框
frame 的 student 属于一个 class_id 和 campus，major 是覆盖维度（rare 为稀少专业）。clusters 给出班级访问固定成本和每人访谈工时。eligibility 表示抽样框资格，不等同是否回答。dispositions 中 refused、absent、out_of_frame 各有独立含义；该数组是历史描述性记录，新批次的现场事件通过 receipt 操作登记到具体 draw_id。

## 设计语义（已实现）
多阶段设计：校区分层全入 → 班级阶段（含稀少专业的班可设为定点必访，其余班校内简单随机抽 m 个）→ 班内按稀少/非稀少专业分层（稀少专业全取，非稀少专业简单随机抽 n 个）。学生 j 的一阶入样概率 π_j = 入班概率 × 层内条件概率；二阶概率按校区独立、校内并班概率、班内层结构给出闭式。plan 用抽样框中的 survey_value 计算 HT 总量估计的精确设计方差作为设计间比较基准；estimate 用受访者的一阶、二阶概率计算 HT 点估计与设计方差。每校区仅抽 1 个非定点班、或层内仅抽 1 人时，相应方差成分无设计无偏估计，工具返回 null 与原因，不编造数值。

## 现场处置语义（已实现）
缺席、拒访、不在抽样框是不同事件：拒访/缺席可对同班同专业层启用事先随机排序的备用；框外个体不替补，而是从估计总体中剔除并重新声明总体规模。替补启用后，最终样本不再是原设计的概率样本：design_based 视图只含正式名单受访者（权重 1/π，并声明无响应未建模的偏差风险）；substitution_view 在"同层可交换"的显式模型假设下让替补沿用被替者权重，且不提供设计方差。全部拒访时点估计为 null，不得以 0 或填补值冒充观测。

## 统计可用性
设计、抽取、替补和估计共享 app/design.py 中的同一份概率语义，抽签批次、回执与替补全部持久化可复查。无响应不是已知随机样本缺失，任何调整都必须以显式假设标注，不允许静默。允许比较不同可行设计，不规定单一抽样算法。

## 小总体基准
analysis_cases 中的六人两班抽样框可枚举全部可能名单，用于核对真实入样概率、零机会和设计方差（tests/test_domain.py 的 EnumerationTests 将闭式结果与全枚举逐一比对）。变更备用方案后不能仍用原来的概率宣称无偏。稀少专业无法同时覆盖、单班预算不足和全部拒访需要给出可操作的限制，而非填造响应值；impossible 与 all_refused 两个用例已纳入回归。
