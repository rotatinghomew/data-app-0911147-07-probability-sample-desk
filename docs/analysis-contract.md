# 分析资料与解释边界

## 抽样框
frame 的 student 属于一个 class_id 和 campus，major 是覆盖维度。clusters 给出班级访问固定成本和每人访谈工时。eligibility 表示抽样框资格，不等同是否回答。dispositions 中 refused、absent、out_of_frame 各有独立含义。
## 统计可用性
设计、抽取、替补和估计应共享明确的概率语义，不能只记录随机种子。需说明一阶和估计方差所需的二阶信息如何取得或近似，以及相应限制；无响应不是已知随机样本缺失，调整需可解释。允许比较不同可行设计，不规定单一抽样算法。
## 小总体基准
analysis_cases 中的六人两班抽样框可枚举全部可能名单，用于核对真实入样概率、零机会和设计方差。变更备用方案后不能仍用原来的概率宣称无偏。稀少专业无法同时覆盖、单班预算不足和全部拒访需要给出可操作的限制，而非填造响应值。
